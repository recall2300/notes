# Notes

개인용 Android 앱의 설치 파일을 올려 두는 곳이에요.

## 설치

1. 폰 브라우저에서 아래 링크를 열어 `notes.apk`를 받아요. 항상 최신 버전이 받아져요.
   https://github.com/recall2300/notes/releases/latest/download/notes.apk
2. 받은 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용해요.
3. 설치가 끝나면 앱을 열어 안내를 따라 하면 돼요.

새 버전이 나오면 앱 홈 화면 위쪽에 알려줘요. 같은 링크로 받아 설치하면 기존 앱 위에 덮어써져요.
